## 5. Standing rules decided by the user (all subjects)
- Ask about every option before starting a subject (sections, sources, new chapters, old vaults, notation), defaults marked Recommended; if the user is away, take Recommended and record it in LEDGER.md.
- Sources: board papers 2016–2020, 2022 Sem 1+2, 2023–2026 (no 2021); all CISCE specimens of the last 10 years; all CISCE CFPQ editions. Answers from APP / specimen MS / CFPQ keys. Never improvement/supplementary papers. CISCE never publishes board papers, so board copies are third-party (Byju's, CollegeDekho, etc.), checked against the APP.
- Exact presentation: verbatim text, tables as HTML, every figure cropped from the paper PDF; one image per question (shared only within one printed question).
- Mixed-chapter questions: show whole, highlight own parts with `<ins>`, `mixed` banner, marks/answers only for own parts.
- Answer diagrams: official first; our redraw only if blurry and exact, both shown with the standard note.
- Wrong official keys: correct answer + official text verbatim + flag official-key-error + tip "Note: the official key says…".
- Strict variations; out-of-syllabus questions left out with reason (check the 2027 syllabus text before excluding: the Geography population miss happened because this was skipped).
- Replace old vaults with redirects. Commit + push after every verified chapter batch; bump versions.
